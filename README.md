# OpenFlight Build List

I'm putting together a complete parts list for building an OpenFlight launch monitor, and I could use your help getting it right.

I've spent a good while going through the OpenFlight repos and docs, and it's still hard to tell exactly what to order. This list is my best attempt. The goal is a fully battery-powered unit with the TI angle radar.

The list is broken into layers, starting with the case and power as the foundation, then the Pi, the screen, the radars, and the mic:

**[openflight-build-list.md](openflight-build-list.md)**

## How you can help

If you've built one, please check the list and tell me what's wrong or missing. Wrong links, parts that don't fit the enclosure, and things I forgot are all useful.

- **Open an issue** with a quick note, like "the screen link is wrong" or "add this part."
- **Open a pull request** if you want to edit the list yourself. I'll review it and merge it.

You can also reply in the OpenFlight Discord. Changes that land here keep the list up to date for the next builder.

Thanks!
